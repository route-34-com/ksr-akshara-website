🏫 A pitch prototype for a new ksrakshara.org (CBSE school, Tiruchengode), built with the school's own content, photos and logo.

The site is static HTML generated by Python, with no framework and no npm, and combines:

   🐍 **A Python build script** (`build.py`) that generates every page, pointing photos at their WebP copies

   🌳 **An interactive emblem tree** — each leaf traced from the school logo, swaying in the wind and opening its own story

   📰 **News that updates itself** from the school's YouTube channel

Every page keeps the **same URL slug as the live site**, so existing Google rankings and links carry over.

## Features

- **15 pages** at the same URLs as the live site: `/`, `/about-us/`, `/about-us/management/`, `/about-us/why-akshara/`, `/about-us/documents-information/`, `/methodology/`, `/life-akshara/`, `/sports/`, `/holiday-assignments/`, `/facilities-hostel/`, `/facilities-transport/`, `/admission/`, `/testimonial/`, `/join-us/`, `/contact-us/`
- **`/akshara-tree/`** — the school emblem's tree as a full-screen interactive piece. Each leaf is traced from the emblem along its white gaps, in the leaf's own blue from the logo. Wind sways the crown and rustles each leaf, leaves drift across the screen, the pointer stirs nearby leaves, and a switch in the dock pauses it all (it stays off for visitors who prefer reduced motion). Tapping a leaf lights it up and opens its story in a glass card. Links like `/akshara-tree/#football` open a specific leaf
- **`/events/`** — news and events, at the same slug their WordPress events page used. Stories come from the school's YouTube channel; the three newest also appear on the homepage
- **Fast** — homepage weighs 333 KB and scores 96 for performance on a phone; accessibility, best practices and SEO all 100
- **Light and dark themes**, a floating WhatsApp button and `School` schema.org data for Google
- **Enquiry form** with inline validation, error and success states, ready to connect to email, WhatsApp or a CRM

## Installation

### Prerequisites

- [Python 3](https://www.python.org/downloads/) (`build.py` needs only the standard library)
- Optional: Pillow, fonttools and brotli for the image and font scripts
- [Git](https://git-scm.com/downloads)

### Step 1: Clone the Repository

**Option A: Using VS Code Terminal**
1. Open Visual Studio Code
2. Open a new terminal (Terminal → New Terminal or ``Ctrl+Shift+` ``)
3. Navigate to your desired directory:
   ```bash
   cd path/to/your/desired/folder
   ```
4. Clone the repository:
   ```bash

   ```
5. Open the project folder:

6. Open the project in VS Code:

## Usage

### Building and Previewing

```bash
python3 build.py              # regenerates every page from build.py
python3 -m http.server 8000   # then open http://localhost:8000
```

Opening `index.html` directly also works, but the map and the campus film need a server. Use `python` instead of `python3` on Windows.

### Scripts

| Script | When to run | What it does |
| --- | --- | --- |
| `python3 build.py` | after any content change | builds every page, pointing photos at their WebP copies |
| `python3 news_feed.py` | to refresh news | pulls the latest YouTube videos (title, date, summary, thumbnail) into `assets/data/news.json` |
| `python optimize_images.py` | after adding photos | writes WebP copies sized for display (needs Pillow) |
| `python vendor_assets.py` | after using a new icon | self-hosted fonts plus an icon font cut down to the icons in use (needs fonttools) |

Run the last two with the virtual environment from Step 2 activated.

### Editing Content

- Every page's HTML lives in `build.py`; `PAGES` lists slug, title, description and function. Never hand-edit the generated `index.html` files
- Styles: `assets/css/site.css` (hand-written). `assets/css/vendor.css` is generated
- Interactivity: `assets/js/site.js`, no dependencies
- The tree: `tree_geometry.py`, with leaf data in `assets/data/akshara-tree-logo.json`

**Important:** keep every URL slug identical to the live site, and keep content real (facts, names, numbers and news come from ksrakshara.org or the school's YouTube channel). More rules are in `CLAUDE.md`.

## Pitch Talking Points

| Current site | This concept |
| --- | --- |
| The homepage has three teaser cards and one paragraph. | The homepage tells the whole story: stages, awards, results, sport, admissions. |
| The strongest proof is buried on inner pages: 3x British Council ISA award, Nobel laureate visits, IIT Jodhpur and medical college results. | That proof sits on the homepage, in the facts band, the bento grid and the testimonials. |
| Admission dates and age eligibility are only on the Admission page. | Dates, ages, steps and an enquiry form are on the homepage. |
| The enquiry form has three fields and no validation. | Inline validation, error states, success state and a boarding preference. Ready to connect to email, WhatsApp or a CRM. |
| The "Eight domains" appear only as an image, so Google and screen readers can't read them. | They are real text. |
| Some background images load over plain `http://` (mixed content). | Everything is local or HTTPS. |
| The logo is a 2560px JPG. | Optimised assets (about 3.8 MB for all images). |
| No news: the events plugin is installed but empty. | News and events that update automatically from their YouTube channel, plus a notices panel. |
| Homepage weighs 4 MB and scores 46 for performance on a phone. | Homepage weighs 333 KB and scores 96; accessibility, best practices and SEO all 100. |
| No dark mode, no WhatsApp shortcut, no structured data. | Light and dark themes, a floating WhatsApp button, and `School` schema.org data for Google. |

## Troubleshooting

- **Changes don't show** — run `python3 build.py` again; the page files are generated
- **Map or campus film doesn't load** — open the site through the local server, not as a `file://` page
- **News is old** — run `python3 news_feed.py`, then `python3 build.py`
- **A new icon shows as a blank box** — run `vendor_assets.py` to add it to the trimmed icon font
- **Something only breaks on iPhone** — test in WebKit (Safari), not only Chrome; this site has had Safari-only bugs

## Project Structure

```

├── tree_geometry.py         # The emblem tree

│   ├── js/                  # site.js, all interactivity
│   ├── data/                # news.json, tree leaf data, tree icons
│   ├── fonts/               # Self-hosted fonts
│   └── img/                 # Photos and WebP copies
├── index.html               # Homepage (generated)
├── <slug>/index.html        # Other pages (generated)
├── CLAUDE.md                # Rules that are easy to break
└── README.md                # This documentation
```
